Ctrl+L

Очистить экран терминала - clear

Сбросить текущий терминал - reset

Посмотреть историю всех ведённых команд - history

выполнить команду по порядковому номеру - shell

Выполнить последнюю команду из history - shell

### Linux

Получить информацию по дистрибутиву. - lsb_realese -a или fastfetch или технические подробности inxi -F

получить температуру CPU/GPU и скорость вращения вентеляторов - sensors

Получить состояние оперативной памяти и подкачки (swap) - free -hf

получить id текущего пользователя - id

Получить список групп, в которых числится текущий пользователь - groups

#### Софт

Показать каледнарь - cal

Поулучить дату и время - date

Получить содержимое текстового файла - cat имя_файла

Отредоктировать файл - nano_файл

Получить имя компьютера - hostname

Получить текущий ip компьютера - hostname -i

Информация по сети - ifconfig или ip -c a

Пинг адреса - ping 8.8.8.8 ping ya.ru (выход ctr+c)

Выполнить пинг указанное количество раз - ping -c 4 ya.ru

Получить информацию по домену - whoise ozon.ru

Получить список портов - netstat -an

Получить маршруты - route

### Управление компьютером

Перезагрузка - reboot/sudo shutdown -r now/sudo systemctl reboot

Выключение - poweroff

### Файловые операции

Получить путь к текущей дериктории - pwd

Получить содержимое текущей дериктории - ls
