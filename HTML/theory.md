# 1.  HTML : Введение

HTML - язык гипертекстовой разметки (HyperText MarkUp Language).
web-стрницы. всё то, что считывается браузером.
Браузер - движок обработки нашего кода.

Приложения бывают двух видов: тонкий клиент (приложение мало весит и оно развёрнуто на сервере организации - клиенты отключаются по протоколу HTTP/HTTPS (заходим на сайт)) и толстый клиент (приложение много весит и устанавливается в оболочку OC). 

Примеры тонкого клиента (Ms Teams, Discord, Skype)
Примеры толстого клиента (Игры, 1c, СУБД, V, МБ приложение)

HTML - каркас страницы (веб-приложение) в браузере. Состоит из тегов (блочные и строчные) Внутри тэгов находится контент (текст, изображение, кнопки, списки, таблицы, формы).

Примеры парных тегов:
<head></head>
<div></div>
<body></body>
<main></main>
<footer></footer>
<hav></nav>
<article></article>
<section></section>
<aside></aside>

<meta>

Комментарии в html <!-- -->

1. Блочный элемент - контейнер парный тег и границы. Основные правила:
Блочный элемент по умолчанию занимает всю ширину экрана пользователя.
Блочные элементы распологаются друг под другом (если не вложены, а идут друг за другом в коде) Высота блочного элемента высчитывается по высоте содержимого контента внутри этого элемента.

Основные семантические теги:
1) Header - "Шапка сайта". Секция для вводной информации сайта или группы навигационных ссылок. Может
содержать один или несколько заголовков, логотип, информацию об авторе.
2) Main - "Тело сайта". Контейнер для основного уникального содержимого документа. На одной странице должно
быть не более одного элемента.
3) Footer - "Подвал сайта".
4) Nav - Секция с навигацией (навбар).
5) Article - Раздел контента, который образует независимую часть документа или сайта, например, статья в
журнале, запись в блоге, комментарий.
6) Section - Определяет логическую область (раздел) страницы, обычно с заголовком.
7) Aside - Представляет контент страницы, который имеет косвенное отношение к основному контенту страницы/сайта.
8) Div - Элемент-контейнер для разделов HTML-документа. Используется для группировки блочных элементов с целью
форматирования стилями.
